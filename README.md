## ✨ دربارهٔ پروژه

در این پروژه، الگوریتم **Gradient Descent** روی بخشی از یک نقشهٔ ارتفاعی اجرا می‌شود تا حرکت از نقطهٔ شروع در جهت کاهش ارتفاع را به‌صورت سه‌بعدی مشاهده کنیم.

سطح زمین با استفاده از `Matplotlib` رسم می‌شود و مسیر حرکت الگوریتم با خط قرمز، نقطهٔ شروع با آبی و نقطهٔ پایان با قرمز مشخص شده است.

## 🧰 ابزارهای استفاده‌شده

- **Python** — پیاده‌سازی الگوریتم
- **NumPy** — محاسبات عددی و محاسبهٔ گرادیان
- **Matplotlib** — رسم سطح سه‌بعدی و نمایش مسیر

## 🚀 اجرا

۱. وابستگی‌ها را نصب کنید:

```bash
pip install numpy matplotlib
```

۲. کد پروژه را در فایلی مانند `main.py` ذخیره کنید و اجرا کنید:

```bash
python main.py
```

پس از اجرا، نمودار سه‌بعدی نمایش داده می‌شود و تصویر خروجی با نام `ball_result.png` ذخیره خواهد شد.

## ⚙️ پارامترهای اصلی

| پارامتر | توضیح |
|---|---|
| `row, col` | موقعیت اولیه در شبکهٔ ارتفاعی |
| `l_r` | نرخ یادگیری (گام حرکت در هر تکرار) |
| `iter` | تعداد تکرارهای الگوریتم |
| `np.gradient(z)` | محاسبهٔ گرادیان سطح ارتفاعی |

## 🧭 ایدهٔ الگوریتم

در هر تکرار، گرادیان ارتفاع در موقعیت فعلی محاسبه می‌شود و مختصات شبکه در جهت مخالف گرادیان تغییر می‌کنند. این کار معمولاً باعث حرکت به سمت ارتفاع کمتر می‌شود.

> **نکته:** این پروژه یک نمایش آموزشی ساده است؛ چون گرادیان روی اندیس‌های سطر و ستون محاسبه می‌شود، گام حرکت مستقیماً بر اساس مختصات جغرافیایی یا مقیاس واقعی زمین نیست.
